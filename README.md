# Hiker для Android

Hiker помогает организовать поход: собрать команду, распределить снаряжение,
составить раскладку, посмотреть трек и учесть расходы.

## Скачать

[Скачать Hiker для Android (APK)](https://github.com/DonStarkoff/hiker-downloads/releases/latest/download/Hiker-android.apk)

[Сайт Hiker](https://hikerteam.app) · [Все версии](https://github.com/DonStarkoff/hiker-downloads/releases)

## Установка

1. Скачайте файл `Hiker-android.apk` на Android.
2. Откройте файл. Если Android спросит разрешение на установку из этого источника,
   разрешите установку для браузера или файлового менеджера, которым открываете APK.
3. Войдите в свой аккаунт Hiker. Сайт и приложение используют одни данные.

## Обновления

Совместимые обновления загружаются через Expo при запуске и применяются
при следующем полном запуске приложения. Для изменений, требующих новой
полной сборки, здесь появится новый APK. Устанавливайте его поверх предыдущего
с сохранением данных приложения.

Это версия MVP. В Android карта пока показывает схему трека, а скачивание GPX
отдаёт исходный файл. Карта OpenStreetMap и экспорт добавленных точек доступны
в веб-версии.
