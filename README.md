# Hiker для Android

Hiker помогает организовать поход: собрать команду, распределить снаряжение,
составить раскладку, посмотреть трек и учесть расходы.

## Установка

1. Скачайте файл `Hiker-android.apk` на Android.
2. Откройте файл. Если Android спросит разрешение на установку из этого источника,
   разрешите установку для браузера или файлового менеджера, которым открываете APK.
3. Войдите в свой аккаунт Hiker. Сайт и приложение используют одни данные.

## Обновления

В установщике Android 5 и новее автообновление включено по умолчанию.
Его можно отключить в настройках. Выбор сохраняется на устройстве.
Кнопка «Проверить и загрузить» работает и при выключенном автообновлении.

Совместимые обновления загружаются через Expo в фоне, пока приложение открыто
и есть интернет. Они применяются при следующем полном запуске.
Уже загруженное обновление применится и после выключения переключателя.
Hiker не перезапускается посреди заполнения формы.

Для изменений, требующих новой полной сборки, здесь появится очередной APK.
Устанавливайте его поверх предыдущего с сохранением данных приложения.

Это версия MVP. Начиная с установщика 7, Android показывает карту OpenStreetMap
с треком и общими точками. Экспорт GPX включает добавленные точки и открывает
системное меню отправки файла. Для перехода с установщика 5 или более старого
на версию с картой установите новый APK поверх прежнего.

## Hiker на iPhone

Откройте [hikerteam.app](https://hikerteam.app) в Safari, нажмите «Поделиться»,
затем «На экран Домой» и «Добавить». Если доступна опция «Открывать как
веб-приложение», включите её. Hiker будет открываться с отдельной иконки
и использовать тот же аккаунт. Для загрузки и синхронизации нужен интернет.
